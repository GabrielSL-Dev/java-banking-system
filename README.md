# 💳 Java Banking System

Console-based banking system developed in Java using Object-Oriented Programming (OOP) concepts.

---

## 🚀 Features

* Create account
* User login
* Deposit money
* Withdraw money
* Check account balance

---

## 🛠️ Technologies

* Java
* Object-Oriented Programming (OOP)
* Git & GitHub

---

## 📚 About the Project

This project simulates a simple banking system through the console.
It was created to practice core programming concepts such as:

* Encapsulation
* Classes and Objects
* Data validation
* User interaction via terminal

---

## 🎯 Future Improvements

* Add graphical interface (GUI)
* Connect to a database
* Implement password encryption
* Add transaction history
